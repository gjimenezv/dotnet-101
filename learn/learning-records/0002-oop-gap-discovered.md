# Gap de OOP más profundo de lo esperado: no recuerda clases/constructores

Durante la lección 1, el usuario pidió explícitamente repasar constructores, modificadores de acceso (public/private/protected), interfaces, clases abstractas y herencia — "no recuerdo nada de las clases". Esto es más básico de lo que el plan original asumía (lección 1 solo tocaba propiedades y sintaxis general, sin cubrir OOP en profundidad).

**Implicación:** se insertó una lección nueva (0002-oop-fundamentals) entre la de sintaxis C# y la de Web API, porque controllers/DI/EF Core dependen directamente de estos conceptos. Para sesiones futuras: no asumir que "sabe C#" implica que sabe OOP — verificar explícitamente antes de construir sobre interfaces o herencia.
